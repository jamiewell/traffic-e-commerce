  Kafka 이벤트로 끝까지 동작하는 것.

    주문 생성 -> 재고 확인/차감 -> 결제 -> 배송 요청 -> 배송 생성(SHIPPED) -> 배송 완료(DELIVERED)

  (MSA 분리, Outbox, DLT 등은 MVP 이후 단계 - 맨 아래 "다음 단계" 참고)

  P1 : 사가 흐름이 이어지지 않는 로직 오류 / 미구현
  P2 : 동작은 하나 잘못된 결과를 내거나 위험한 부분
  P3 : 정리/개선 (MVP 필수 아님)
